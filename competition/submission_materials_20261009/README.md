# 智接 WireMind 比赛材料公开版

本目录同步报告、作品信息、部署说明、过程记录和AI使用声明。沿用提交材料要求的章节结构，学校、队员信息与签字由团队本人补齐。

报告公开版省略内嵌照片；经提供者追加授权，机柜原始试用照片已单独放入[机柜案例](../../examples/cabinets/README.md)，完整10页答辩课件也同步提供。密钥、无关私人样本与本机私人取证文件仍不公开。

新增亮点为本地视觉与云端推理协同、纯掩膜与脱敏局部图双输入、四档思考强度、本机密钥记忆、逐框证据门控和复检追溯。云端能力通过`启动大模型复核版.bat`提供，正式视觉主线保留原入口，完整SAM Release不变。

## 使用新入口

先按仓库恢复说明准备Python依赖及模型，再运行仓库根目录的`启动大模型复核版.bat`。勾选“启用DeepSeek辅助复核”才显示设置；保存密钥后以后可留空使用。默认轻量思考，模式选择会记住；密钥仅保存于忽略发布的`config/deepseek_mask_review.local.json`，不是报告的一部分。

完成本地检测后，选择输入方式并确认外发。脱敏局部图须检查敏感文字，小块马赛克不保证文字不可读。不将视觉分级当作电气导通判定。标准和深度模式的输出预算与等待上限有限，失败时保留本地结果。

本轮轻量思考同图案例返回两个可见变化建议；该例不代表跨机柜准确率。相关真实回退与验证记录包含在测试材料中。
