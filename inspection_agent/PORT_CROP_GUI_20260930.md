# 可选端口提示界面（2026-09-30）

原 DINO/SAM 界面新增“启用可选端口提示”复选框，默认关闭。完成原视觉复核后，确认适用场景，点击“生成端口局部提示”。后台线程运行已验收的单图入口，原差异候选和 Agent 人工复核结论保持原义。

“端口局部提示”页显示黄色原父框和蓝色小提示框；“端口局部对比”页显示参考图/待检图的对应局部。每图最多1个新提示。`port_crop_review.json` 保存完整可选结果，原报告的 `optional_port_crop` 保存摘要，不更改 `review_regions`。

当前监督模型仅验收现有机箱数据。场景选择由操作者确认，参考图SHA、尺寸及权重/校准/辅助代码指纹仍须匹配；未知或机柜场景回退。启用复选框不会自动开始大模型推理，也不会重跑SAM。

配准模块仅新增 `source_to_reference_homography` 报告字段，算法、阈值和输出图像保持原逻辑。GUI记录原图SHA以及分析期间是否一致，避免事后用新的图指纹冒充旧几何身份。未保存矩阵的旧报告需要重新视觉复核；发生局部ECC形变校正时暂不叠加提示。

开关关闭后清除提示展示；输出文件保留作为历史证据。模型/输入检查失败时提示回退原因。提示运行期间避免启动另一轮分析或外部复核，完成后恢复操作。此接入仍不提供端子身份、电气连通或完整接线拓扑。

Codex工作区 `artifacts/port_crop_gui_20260930` 保存源码改动前备份、验证与界面截图。精度指标沿用既有验收；GUI当前生成的父框来自其原流程，因此固定父框重放一致不代表完整GUI检测链取得同样的精度指标。
