# WireMind：算法改进检索与下一轮方案

2026-09-28。状态：完成论文、作者仓库及维护方实现的筛选；本文件是研究建议，不是新算法实测报告。正式算法和候选预算未修改，没有安装依赖、下载权重或新数据。

## 为什么还值得继续

上轮失败的是「高分辨率局部正常参考排序＋保留一个原主证据框」的正式升级，不是整个算法方向被证明不可行。

已核对项目 HIGHRES_LOCAL_AUDIT_20260928.md 与源码：固定融合的来源框交集由146/245到169/245，但走线类由14/19到9/19，图片等权覆盖由65.44%到61.18%。总交集改善不能抵消某类明显退步。上述都是来源框定位指标，不是现场准确率。

源码中的局部参考库允许不同位置分别选不同正常图片及邻近格子。因此它可能把多个正常例子的局部证据拼成一种实际不存在的正常布局。这是待验证假设，并非已经证实的退步原因；当前半径限制已经含有部分位置约束，不能称为完全不看位置。

## 下一轮：先检验位置统计，不再扫描分辨率

以下是预先记录的实验设计，尚未执行。目标是判断「空间位置的正常统计」能否补足走线证据，而不是给几张走线图写例外。

1. **冻结输入与比较口径。** 继续使用现有对齐、392 输入、相同原候选池及原每图候选数量。正式图像门、SAM3 路径和预算6不变。先做单分支证据诊断，再做固定融合；不增加框数掩盖排序问题。
2. **独立拟合与校准。** 对 train01 正常图片按编号排序，前80张拟合、接下10张留作间隔、末30张仅做校准。写出完整成员清单，不把校准图放进拟合库。编号间隔只能减轻相关性，不是真正的新场景隔离。
3. **位置分支。** 使用缓存 DINO 特征，固定随机种子选32维；每个格点拟合带正则的正常协方差，计算位置相关 Mahalanobis 分数。固定使用0.1比例的球形协方差收缩及数值下界，先测试奇异矩阵、常量通道和正常偏移情形。该模型只表达空间外观偏离，不表达电气连接关系。
4. **公平对照。** 局部正常参考分支也只使用上述80张拟合图，并保持 k=3、邻域半径1。原120张参考的旧报告仅作历史参照，不能把参考集合变化造成的效果归因于空间建模。
5. **正常校准。** 每个分支用30张正常校准图的图像95百分位分数估计其95%分位尺度；尺度不足时明确报错或应用预先记录的数值下界。图像尺度用于热图/候选融合只是待检验的启发式，不宣称候选概率。30张图也不足以可靠估计99%尾部或保证现场误报率。
6. **固定融合。** 单独保存局部、位置两张证据图；按正常尺度归一后，固定取二者逐格最大值作为一次探索性融合，不扫描权重/幂次。保留原跨尺度首候选，其余位置按融合热图的候选区域95百分位排序。两分支对所有图执行，不读取故障类别选择算法。融合后在正常校准图上重新评估整体响应，不能假设分支各自校准后融合就没有误报。
7. **整批评价。** 对全部30张 val01 输出原基线、80图局部参考、位置分支、固定融合四组报告，并保留逐图证据。评价交集、IoU、整图覆盖、图片等权覆盖、三类覆盖、正常候选及热图响应。test01不参与调参；已反复分析的 val01只能支持开发期比较，不能作新场景泛化证明。

## 判定与后续分支

- 不只看总来源框交集。最低要求：整图覆盖不低于15/15，图片等权覆盖不低于原基线65.44%，走线来源框覆盖不低于14/19；同时记录损伤、断接各类退步。以上是保守开发门槛，不是统计显著性或独立泛化证明。
- 若位置分支不能在正常图噪声之上提供走线证据，就停止该方案的候选排序优化；优先检查对齐误差和位置模型假设，而不是按验证图加规则。
- 若有互补证据但融合失败，下一步检查正常校准及重复候选几何，不继续提高分辨率。探索性最大值融合可能增加误响应，因此不能未经验证直接替换正式路径。
- 若损伤局部信号仍弱，下一项独立实验才是 CNN 中间层正常参考；当前常用 torch checkpoints 目录仅查到 dinov2_vits14_pretrain.pth，不能声称 CNN 权重已经就绪。其他位置是否有权重尚未穷尽核验。
- 若布局统计仍无法覆盖错接，再做组件对应/有限拓扑实验。SAM对象数、可见端点和路线异常均不能直接证明电气通断。
