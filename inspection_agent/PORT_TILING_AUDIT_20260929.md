# 固定插头分块实验：否决，不接正式检测

本轮完成了一个冻结规则的通用分块实验，而没有达到精度提升目标。
原父框和上一轮有效整图插头提示逐字典保持不变，GUI、CNN可选入口、
生产检测和用户原有7个脏跟踪文件均未改。

## 规则和数据边界

运行前固定 `PORT_TILING_PROTOCOL_20260929.md`：1280方块、步长960、
图尾补齐；每张3648x2736图12块。人工裁切边16像素内预测弃权，
类别内IoU .5去重保留最高置信度原几何，不并大外框。CPU4线程、
每次2块、输入960、缓存下限 .001，原生NMS .7/maxdet300。

使用同一个旧3epoch Dell插头监督模型，类别0/1映射源标注3/4。
30张train01正常图完成后冻结门槛：max(.25, 每图最高置信度的p95)
= **0.39880521297454796**。然后完整运行val01的15故障+15正常。
没有新的test01推理、裁剪或阈值搜索，不按图名设置规则或用GT选提示。

全部原父框和已接受整图提示保留；新框仍须有效透视覆盖>=.98、
完整包含某父框且面积<=父框一半，与已有提示IoU<.5；每图最多新增1提示。
预测与评分标注使用上轮实际SIFT H（源文件指纹核对、有效覆盖重建）。
标注是源数据碎片矩形，不是完整线材/损伤mask，也不是电气真值。

## 完整验证结果

| 项目 | 上轮父框+整图提示 | 再加分块提示 |
| --- | ---: | ---: |
| 故障图片存在标注交集 | 15/15 | 15/15 |
| 源片段有交集 | 164/245 | 164/245 |
| IoU>=.1 | 25/245 | 25/245 |
| IoU>=.5 | 5/245 | 5/245 |
| 平均最佳IoU | .04056456 | .04056456 |
| 故障复核区域 | 71 | 71 |
| 正常复核区域 | 37 | 38 |
| 本轮新增正常提示/图片 | 0/0 | 1/1 |

新提示类别一致的一对一IoU>=.5评分：TP0、未匹配提示1、漏56个端口片段。
这只评新提示，不是整系统准确率；正常原来已有37个粗区域。
新增提示出现在normal_105，置信度 .540365；正常图局部结构被模型当作
unplugged_plug线索。4个tile支持不能证明它真的断接。

30图合并后的1893个预测：无效1、低于门槛1889、父框条件不满足2、
合格1。过门槛的3个预测来自damaged_035(.442334)、normal_105(.540365)、
normal_126(.422248)，后两张是正常图。大量低分预测不算命中。
这一结果支持“旧整图训练模型直接切块会产生尺度/上下文不匹配”的研究
假设，但不能单凭本轮证明唯一原因，也不能否定所有分块方法。

## 验证和报告更正

60图源文件及缓存SHA核对、60组NMS精确重放、30组透视/提示精确重放、
倒序输入一致、训练门槛精确重建、父框/已接受提示未变，全部通过。
7分块+9端口提示+11可见几何+7SAM适配器=34项测试通过。
固定四类最小编号控制图和全部3个过阈值图的右列面板已查看。
橙框是过阈值但未必接受的预测，紫框才是新增提示；红框只评分。

冻结原始report.json和实际执行脚本保留不改，以保留推理溯源。
发现原始报告 `baseline.normal_images_with_added_hints` 错把新增分支的1
写入旧分支；旧分支应为0。复核器明确验证这个已知计数问题，
在 `replay_verification.json.corrected_baseline` 给出正确值。
旧/新区域数37/38和所有IoU、几何、推理结果均不受影响。
不能忽略这条更正或把原始这个计数当作旧分支结果。

整批720次tile推理及校准/变换/输出耗时487.159秒，约8.1分钟；
采样最大RSS .865GiB，不是连续测得的真实峰值，也不是DINO/SAM/GUI整链延迟。
旧模型曾经按val选择，校准正常图也曾用于训练；本轮是同设备回顾性验证，
不称盲测、独立校准、跨机柜泛用性、现场准确率或电气连通性。

## 决定和下一入口

预先要求“精确片段增加且正常提示不增加”，本轮两项均未满足：**否决**。
不接GUI或当前CNN CLI，不降低门槛救本轮结果；上一轮5个精确片段中的
有效整图提示保留。通用切块/边缘弃权/NMS工具仅作可复用研究代码。

裁块训练与裁块推理一致的小目标模型，而非继续拿旧模型扫块尺寸/阈值。

正常复核负担。test01不再作为调参集。新训练未开始、泛用性尚未证明。
