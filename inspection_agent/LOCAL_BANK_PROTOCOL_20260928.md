# 局部正常参考试验固定协议

训练参考：全部 train01 正常图120张，对齐到固定 train01 normal_073。验证：val01全部30张图，其中15张正常、15张故障。test01不参与。

特征沿用现有DINOv2模型和整个固定ROI的输入尺寸，不改模型或训练。每个位置允许1个patch的对齐残差；先在每个正常参考图中找到邻域最相似特征，再对3个不同参考图的最近距离取平均。k=3沿用已有正常参考思路，邻域1patch固定，不根据故障标注搜索。以候选所覆盖网格的95百分位距离排序，不据标签挑选候选。

固定比较原输出、单正常参考邻域距离排序、多正常参考距离排序，以及所有合并候选上的多正常排序（后者用于审查放宽筛选的风险）。全部逐图保持原候选数，仅改变选择；正常候选数必然相同，不能凭此声称正常误报得到改善。额外列出正常图距离响应及候选位置变化。来源标注仅用于事后计算定位指标。

按类别和预先固定的三个编号区间检查稳定性，不以总计提高独自作为升级条件。编号不是真实采集批次，现有val01也已多次研究，故没有独立泛化证明。本次仅诊断这种特征是否值得继续；不以少量图的结果追加阈值、网格尺度或参考库子集搜索。

局部网格分辨率很低，细小缺陷可能没有足够特征；若结果不稳定，保留正式基线，并将该限制写入报告。

在首轮验证结果出来前额外预定编号邻近排除压力测试：每张验证图排除训练正常参考中编号差<=10的图片，复用同一算法，分别保存报告和距离图。10沿用已有相关性压力测试，不扫描排除半径。编号只是相关采集的代理，此检查仍不能代替新机箱或真实采集分组验证。
