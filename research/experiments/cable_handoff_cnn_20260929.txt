2026-08-18—自动定位复核版：当前进展与降误判改造建议
============================================================

当前版本
1. 已建立本地 Git 项目：E:\PythonProject10；第一版基线提交为 4e8b100。
2. 当前主入口为“启动装配自动定位复核_结果框版.bat”。窗口使用全图 SIFT 特征匹配 + RANSAC 仿射变换进行自动定位，不再要求每次手工框选模板。
3. 定位通过后，程序在已配置的检查区域内输出：对齐图、综合色差/结构差热力图、红框复核图和 report.json。
4. 窗口结果框分三种状态：
   - 绿色：未发现明显差异；
   - 红色：发现差异，请人工复核；
   - 黄色：无法可靠对齐，请重拍。
   同时显示一行摘要（定位状态、检查区域数、差异区域数），可打开红框图或本次输出目录。

已验证的结论
1. 服务器内存图片存在足够稳定的 PCB/散热片/机箱纹理时，全图自动定位比手工小模板稳定；right3 与 wrong3 可定位，能够将“疑似差异”集中到右上内存槽附近。
2. 插排样本经全图定位后也能将差异集中到检查区域，但强阴影、插孔孔洞、反光和局部遮挡仍会产生碎小红框。
3. 低纹理桌面上的充电头“插上/未插上”样本，缺少共同稳定纹理；传统特征定位无法可靠建立坐标关系。此时黄色“无法可靠对齐”是正确的保护结果，不应硬判正常或异常。

误判的主要来源
1. 对齐残差：即使视觉上已对齐，1—2 像素偏差也会使插孔边缘、文字和线缆边缘出现高差异。
2. 拍摄变化：曝光、阴影、反光、白平衡与清晰度变化会造成非装配差异。
3. 背景或检查区内存在可移动物体：线缆、手影、桌面反光会被当成异常。
4. 单张正确参考图过于严格：参考图本身的偶然阴影或噪点会被误当作标准。

降低误判率的建议（按优先级实施）
第一阶段：不训练模型，先改善传统对比
1. 在 SIFT/RANSAC 初始定位后增加“小范围 ECC 亚像素精修”，但严格限制位移、旋转、缩放范围，避免把真实的装配变化强行拉齐。
2. 使用“局部结构差异 SSIM/MS-SSIM + Lab 色差 + 边缘差异”的融合评分，而不是只用单一像素差或只提高阈值。
3. 在差异掩膜后加入形态学开/闭运算、最小连通域面积过滤、相邻区域合并，并屏蔽对齐后产生的黑边区域；目标是减少细碎红框、保留物体级差异。
4. 对亮度通道做温和的背景光照校正/局部归一化；仅用小核高斯或双边滤波抑制噪点，不能过度模糊，否则会漏掉插头与内存条边缘。

第二阶段：提高“正常”判定的鲁棒性
1. 每种设备、每个固定机位采集 3—10 张正确参考图，先自动对齐，再建立“正常波动范围”（像素中位数图 + 变化容忍图）。
2. 只有待检图超出正常波动范围时才报差异；这比与一张参考图硬比更能抵抗阴影和曝光波动。
3. 检查区域应一次性在正确参考中配置并保存，日常待检只自动定位、自动比对；不应要求操作人员逐张框选。

第三阶段：针对难场景的专用模型
1. 固定机位仍无法提供稳定纹理的场景（例如桌面充电头），应增加固定背景/支架/拍摄框；这是最便宜且最可靠的改进。
2. 若业务必须在随手拍、背景变化大的条件下判断“插上/未插上”，需要采集对应的正确/错误样本并训练状态分类或目标检测模型（如 YOLO）；通用图片差异算法不应承担此类语义判断。

使用边界
绿色仅表示：在“定位通过 + 已配置检查区域 + 当前阈值”下未发现明显视觉差异，不等同于电气、插入力或机械状态合格。
黄色表示：程序没有找到足够可靠的共同视觉基准，应重拍或使用固定夹具，不能把它视为“没有差异”。


如果要进一步提高跨设备、跨角度的泛用性，后续引入学习型匹配/变化检测会比纯 SIFT 更合适：例如用 LoFTR/LightGlue 做更稳的 局部匹配，再用 DINO 特征或训练过的双图变化检测模型做候选判断。它仍然是“任意结构都参与”的路线，不是给每个零件手工写规 则。
