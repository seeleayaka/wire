# WireMind research snapshot, 2026-10-09

The accepted desktop visual-review runtime is preserved. This snapshot adds research source for connection evidence, occlusion experiments, and an opt-in cloud-assisted per-region review window. Research code is not automatically enabled in the accepted runtime.

## Cloud-assisted review

`experiments/llm_recheck_planner.py` produces structured per-region observations and follow-up checks. `experiments/llm_review_priority.py` combines a model suggestion with local evidence gates. The Qt bridge in `experiments/launch_llm_recheck_window_20261008.py` exposes the original priority, model suggestion, final priority and reason.

Only explicitly approved binary mask images and minimal candidate information are sent. API credentials remain local. Input hashes bind suggestions to the matching review task. A priority change is limited to one level and requires compatible local evidence. Regions and the original visual result remain available for human review.

Actual local interface checks returned two valid structured plans. Subsequent priority checks returned one valid response and one rejected response with local fallback. A diagnostic repeat of the rejected case returned a valid response. The retained candidate priorities were unchanged in these observed cases. These checks establish interface behavior, not an electrical fault accuracy improvement or a fresh end-to-end segmentation benchmark.

## Running research code

The research scripts preserve the original Windows workspace configuration. Configure the installed mainline path, Python/Qt environment, model paths and authorized local API configuration before running. Tests referencing local evidence need the original private test fixtures, which are deliberately excluded from this repository. Synthetic unit tests and private-fixture integration tests have different dependencies.

No private photographs, masks, cloud response fixtures, new checkpoints or credentials are included in this update. The existing `backup-20261004` model Release is unchanged. Use its manifest and SHA-256 instructions to restore weights.
