实时相机引导拍摄计划
日期：2026-08-19
状态：待实施（先记录方案；不改变现有离线复核流程）

一、目标
在现有“标准图 + 实际图”复核程序前增加实时取景入口。
相机画面持续分析，动态四边形框自动贴合柜内可检查平面；只有画面满足
拍摄条件时变绿。拍到合格图片后，才进入既有的全局对齐、DINO 差异检测和
后续端子/线材连接判断。

二、边界
1. 当前原型判断的是“照片是否适合视觉复核”，不是直接在实时画面输出 OK/NG。
2. DINO 不参与逐帧预览，避免预览卡顿；仅在拍照冻结后运行。
3. LightGlue 只作为初始锁定或普通特征匹配不可靠时的后备，不作为每帧算法。
4. 不要求人工绘制检查框。柜体正面和待检层由标准图结构自动定位。
5. 对于过斜、过远、遮挡、裁切或模糊的画面，输出“请补拍”，不得当成装配 NG。

三、实时状态机
SEARCHING（红）
  - 尚未找到柜内平面，或匹配点不足。
  - 提示：将柜体正面完整置入画面。

FOUND_BUT_UNSUITABLE（黄）
  - 找到柜体/导轨结构，但存在角度、清晰度、分辨率、遮挡或覆盖范围问题。
  - 提示应具体，例如：请靠近、向左移动、降低倾角、移开前景线缆。

READY（绿）
  - 柜体正面与标准图稳定匹配，局部端子细节达到可判定分辨率。
  - 连续稳定一段时间后允许手动拍照，或按最终选择自动保存。

CAPTURED
  - 冻结一张合格图，调用现有 SIFT/RANSAC/Homography → DINO 融合差异流程。

四、实时检测链路
1. 获取相机帧
   - 第一版兼容电脑摄像头和 USB 摄像头；工业/IP 相机作为后续适配层。

2. 自动找柜内可检查平面
   - Canny/直线检测寻找多条横向导轨、左右框架；
   - 结合标准图的重复端子排特征，生成候选柜内四边形；
   - 过滤地面、柜门、工具、前景线缆等非柜内区域。

3. 动态贴合框
   - 用候选四边形将标准图四角投影到实时画面；
   - 绘制会随相机移动、缩放和透视改变的四边形，而非固定屏幕矩形；
   - 使用上一帧变换作短时跟踪，降低框抖动。

4. 快速对齐质量评分
   - ORB/SIFT 的匹配数量、内点率和重投影误差；
   - 变换后对标准图的覆盖面积与几何合理性；
   - 仅在普通匹配无法稳定锁定时尝试 LightGlue。

5. 可判定性评分
   - 清晰度：拉普拉斯方差或等价清晰度指标；
   - 透视：柜内四边形的梯形程度、导轨平行度；
   - 覆盖：关键两层/目标层是否完整落入画面；
   - 遮挡：前景线、手、工具等遮住端子区域的比例；
   - 分辨率：标准图映射后，端子接线口的最小像素尺寸是否足够。

五、红黄绿规则（初版）
红色：未锁定柜内平面、关键区域缺失、严重遮挡、严重失焦或极端透视。
黄色：已锁定但未达到端子级判断要求，例如距离过远、轻度倾斜或画面边缘裁切。
绿色：全局对齐可靠、目标区域完整、端子口分辨率和清晰度合格，并连续稳定。
注：阈值先按现有图片做初值，接入真实摄像头后再标定；不在无实测前写死数值。

六、与线材连接识别的衔接
绿灯拍照后：
1. 现有全局对齐；
2. 从标准图自动建立端子/接口位置地图；
3. 在每个接口附近比较“端子占用、线端位置、进线方向、局部差异”；
4. 输出疑似漏接、疑似错接、疑似偏位或人工复核。

七、针对已查看现场照片的处理原则
1. 正面近景、两层结构完整：应进入绿色并允许拍摄。
2. 远景正面：可识别柜体，但端子口过小则保持黄色，提示靠近。
3. 斜拍、柜门/地面占比大、外部蓝线或工具进入：保持红色或黄色，不执行正式复核。
4. 不把拍摄条件不合格误判为装配异常。

八、待确认的实现参数
1. 相机来源：内置/USB、工业相机或 IP 相机；
2. 取景目标：整柜两层一次拍摄，还是允许分上层/下层拍摄；
3. 绿灯后动作：自动保存，或由操作员点击确认；
4. 现场允许的最小拍摄距离、补光条件与相机安装位置。

九、建议实施顺序
阶段 A：相机预览窗口 + 红黄绿状态 + 基础清晰度/覆盖检查。
阶段 B：柜内四边形自动定位、透视贴合框、稳定锁定。
阶段 C：复用现有对齐质量报告，生成具体补拍提示。
阶段 D：绿灯拍照并无缝交给既有 DINO 复核。
阶段 E：在合格拍照前提下接入端子地图与线材连接逻辑。
